# Advanced Database Design and Administration

**Youngstown State University — Fall 2026**

This course is offered as a cross-listed course for undergraduate and graduate students:

* **CSCI 4850** — Advanced Database Design and Administration — Undergraduate
* **CSCI 6950** — Advanced Database Design and Administration — Graduate

* **Email:** [amastorga@ysu.edu](mailto:amastorga@ysu.edu)

## Course Overview

This course introduces advanced concepts in database design, development, and administration. Topics include SQL, relational data modeling, entity-relationship diagrams, normalization, physical database design, advanced queries, stored procedures, triggers, data warehouses, transaction management, database administration, security, backup and recovery, and distributed database concepts.

The course includes practical work with SQL and **Oracle APEX**, allowing students to apply database concepts through hands-on exercises and assignments.

## Undergraduate and Graduate Sections

Although **CSCI 4850** and **CSCI 6950** are cross-listed and cover many of the same core topics, graduate students may be expected to complete additional or more advanced work.

### CSCI 4850 — Undergraduate

Designed for undergraduate students, with emphasis on:

* Database design fundamentals
* SQL and query formulation
* Entity-relationship diagrams
* Normalization
* Physical database design
* Advanced SQL
* Views and nested queries
* Stored procedures and triggers
* Data warehouse concepts
* Database administration
* Transaction management

### CSCI 6950 — Graduate

Designed for graduate students, with additional emphasis on advanced database concepts, analysis, and administration.

Graduate-level work may include:

* Advanced SQL problems
* Advanced database design
* ERD and normalization analysis
* PL/SQL
* Database administration
* Transaction management
* Advanced database models
* Distributed and object-oriented databases
* Database security
* Backup and recovery
* Data warehousing
* More advanced assignments and assessments

## Main Topics

The course will cover topics including:

1. Introduction to Database Management
2. Database Development
3. Relational Data Model
4. SQL and Query Formulation
5. Entity-Relationship Diagrams
6. Data Models for Business Databases
7. Database Normalization
8. Physical Database Design
9. Advanced SQL and Matching Problems
10. Views, NULLs, and Hierarchical Queries
11. Stored Procedures and Triggers
12. Data Warehouse Concepts and Management
13. Database Administration
14. Transaction Management

## Software and Tools

Students will work with database technologies and tools including:

* SQL
* Oracle Database
* Oracle APEX
* PL/SQL
* Database modeling and ERD tools

Students should set up their **Oracle APEX environment** early in the semester.
