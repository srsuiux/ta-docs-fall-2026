Create a hands-on student setup and practice document that introduces students to the Oracle APEX Cloud and SQL Workshop environment. The document will serve as a starting point for students before they begin their main assignments.
Students can use this document before or after the first class to set up their APEX environment, explore the platform, create their first table, add sample data, and practice writing and executing basic SQL queries.
The document should be practical and focused on doing, rather than explaining database concepts in depth. It should give students an opportunity to become comfortable with APEX and perform a few basic operations before working on the main assignments.
The document should cover:

Accessing and navigating the Oracle APEX Cloud environment
Setting up and accessing the SQL Workshop/database environment
Creating a first table using SQL
Adding columns and selecting basic data types
Inserting sample records into the table
Running a first SELECT query
Understanding what basic queries such as SELECT, INSERT, UPDATE, and DELETE do
Viewing query results within APEX
Modifying and experimenting with the sample table and its data
Running a few simple queries to explore the data
