## Course Description

CSCI 6950 introduces advanced concepts in **database design, development, and administration**.

The course covers database query languages, transactions, data warehousing, relational calculus, system analysis, concurrency, backup and recovery, database security, and advanced database models. Topics also include distributed databases, object-oriented databases, and online databases.

The course combines conceptual understanding with practical database development and administration using SQL and related database technologies.

---

## Course Goals

By the end of the course, students should be able to:

* Understand advanced database concepts and database management principles.
* Design relational databases using appropriate modeling techniques.
* Develop and evaluate Entity-Relationship Diagrams (ERDs).
* Apply normalization principles to improve database design.
* Formulate and optimize SQL queries.
* Work with advanced SQL concepts including nested queries, views, and hierarchical queries.
* Understand physical database design considerations.
* Apply stored procedures and triggers using PL/SQL.
* Understand transaction management and concurrency.
* Explain database backup, recovery, security, and administration concepts.
* Understand data warehousing concepts and their role in database systems.
* Analyze advanced database design and administration problems at a graduate level.

## Learning Approach

This course follows a progression from **database fundamentals → relational modeling → SQL → database design → normalization → advanced SQL → PL/SQL → administration → transaction management**.

The goal is not only to memorize SQL syntax, but to understand **why database systems are designed and administered in particular ways**.

Students should expect to:

1. Learn the underlying database concept.
2. Study examples and design patterns.
3. Implement the concept using SQL or database tools.
4. Solve progressively more complex problems.
5. Analyze the results and identify potential improvements.
6. Apply multiple concepts together in graduate-level problems.

# Graduate-Level Expectations

Because CSCI 6950 is a **graduate-level course**, students are expected to go beyond simply producing working SQL statements.

Graduate-level work should demonstrate the ability to:

* Explain the reasoning behind a database design.
* Evaluate alternative database designs.
* Identify design problems and propose improvements.
* Analyze normalization decisions.
* Construct increasingly complex SQL solutions.
* Explain the behavior and limitations of database operations.
* Connect theoretical database concepts with practical implementations.
* Investigate problems independently.
* Justify technical decisions rather than relying only on trial and error.

A solution that **works** is not necessarily a solution that is **well designed**.

## Course Philosophy

> **Learn the concept → understand why it matters → implement it → test it → analyze it → improve it.**

The objective of this course is not simply to learn how to write database queries. It is to develop the ability to **design, develop, analyze, and administer database systems thoughtfully and systematically**.
