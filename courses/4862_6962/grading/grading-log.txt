Project structure notes (not scored):
  - Your app is inside the Pages folder: app.js, package.json and node_modules are all sitting inside Pages/. That folder is only supposed to hold the html pages and the images folder. Move app.js and package.json up to the main project folder, next to Pages, and run npm install there. Then you start it with node app.js from the project folder and it serves the files in ./Pages.
  - You have 2 package.json files: I found them in: Pages/package.json, package.json. You only need one, at the top. This usually happens when npm init or npm install gets run in the wrong folder, and then it's not clear which one is the real project.
  - You have 2 node_modules folders: I found them in: Pages/node_modules, node_modules. Install once, in the folder that has package.json. Right now the same packages are stored twice.
  - The package.json at the top doesn't say how to start the app: It has no "main" and no "start" script, so node app.js or npm start from the top folder fails with "Cannot find module". I had to dig into Pages/ to find your app.
  - The index page is called Index.html: Rename it to index.html, all lowercase. On Linux and most web hosts file names are case-sensitive, so Index.html and index.html are different files.
Other notes (not scored):
  - Your code keeps its own list of valid ISBNs. You don't need that. Just ask sendFile for the file and, if it isn't there, the callback gives you err.code === "ENOENT" and you can send "File Not Found". Then adding a book is only adding a file.
