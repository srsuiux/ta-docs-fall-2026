Darius Price
Thanks for your submission. Your single /select route works, all three books load, and your not found messages for a missing book and a wrong page are in place. Your book pages are complete and the code is commented.

A few things to work on in the code:
- Use sendFile with the {root: ...} option, and use path.resolve instead of path.join to build the folder path.
- Add an error handler at the end of app.js that sends "Server Error", for example app.use((err, req, res, next) => ...). I could not get a "Server Error" message when I forced an error.
- You don't need the list of valid ISBNs. If sendFile can't find the file, its callback tells you, and you can send "File Not Found" from there.

The bigger thing is the project setup. app.js, package.json and node_modules are all inside the Pages folder, but Pages should only hold the html files and the images folder. There are also two package.json files and two node_modules folders, and the package.json in the main folder has no start script, so running node app.js or npm start from the main folder doesn't work. Please move app.js and package.json up next to Pages, keep just one package.json and one node_modules, add a start script, and rename Index.html to index.html (all lowercase). That will make your project much easier to run and to share.
