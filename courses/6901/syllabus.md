## Course Description

CSCI 6901 introduces the **principles of computer programming** for graduate students who have little or no previous computer science experience.

The course focuses on programming techniques, computational problem analysis, fundamental programming concepts, and practical software development. Students learn the significant features of a programming language and apply those concepts through programming assignments and projects appropriate to their backgrounds and needs.

The course uses **C++** as the primary programming language.

---

## Course Goals

By the end of the course, students should be able to:

* Understand fundamental programming concepts and terminology.
* Analyze computational problems and develop appropriate solutions.
* Write, compile, execute, and debug C++ programs.
* Work with fundamental data types and expressions.
* Use conditional statements and control structures.
* Implement repetition using loops.
* Design and use functions.
* Work with arrays and vectors.
* Understand pointers and structures.
* Implement sorting and searching algorithms.
* Read from and write to streams and files.
* Understand object-oriented programming concepts.
* Design and implement classes.
* Apply software testing techniques.
* Understand software components and modular development.
* Explore the role of artificial intelligence in programming.
* Develop programming solutions through increasingly complex projects.

# Learning Progression

The course is structured as a progressive programming sequence.

Students move from basic programming concepts toward more advanced programming and software-development practices:

**Problem Analysis → Fundamentals → Control Flow → Functions → Data Structures → Algorithms → Object-Oriented Programming → Testing → Components → AI**

The objective is to build programming ability incrementally rather than introducing advanced concepts before the foundational concepts are understood.

# Graduate-Level Expectations

Although this course is designed for graduate students who may have limited previous computer science experience, the expected outcome is still **graduate-level problem solving**.

Students are not expected to arrive as experienced programmers. However, they are expected to progressively develop the ability to:

* Analyze a problem before writing code.
* Break complex problems into smaller components.
* Explain why a particular programming approach was selected.
* Write readable and maintainable code.
* Debug programs systematically.
* Test solutions rather than assuming they work.
* Compare alternative implementations.
* Understand the limitations of a solution.
* Apply programming concepts to unfamiliar problems.
* Develop increasingly independent programming skills.

The objective is not simply:

> **"Can you make the program run?"**

It is also:

> **"Can you explain the problem, justify your approach, test your solution, and improve it?"**

# Artificial Intelligence

The course includes **Artificial Intelligence** as a topic near the end of the semester.

When AI tools are permitted for coursework, students remain responsible for understanding and verifying the resulting code.

Students should be able to:

* Explain AI-generated code.
* Test generated solutions.
* Identify incorrect or inefficient implementations.
* Modify generated code appropriately.
* Recognize limitations of AI-assisted programming.
* Distinguish between using AI as a development tool and outsourcing the learning process to AI.

AI should support programming education, not replace the development of fundamental programming skills.

## Course Philosophy

> **Understand the problem → design the solution → write the code → test it → debug it → explain it → improve it.**

The goal of CSCI 6901 is not simply to teach students C++. It is to develop a **computational problem-solving mindset** that students can carry into advanced coursework, research, software development, data science, and other areas of computing.
